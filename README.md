# Oxidant Homebrew tap

Homebrew formulae for [Oxidant](https://github.com/OxidantData/Oxidant) — a drop-in Apache Spark replacement on a vectorized CPU core.

```sh
brew install oxidantdata/tap/oxidant
```

The `oxidant` formula is published automatically by the release pipeline
([cargo-dist](https://axodotdev.github.io/cargo-dist/)) on every version tag —
no manual edits needed. First formula lands with the first release.
